Build a Clinic Operations Copilot multi-agent system using ADK and 
Antigravity 2.0.

- 3 MCP servers running and tested (clinic_warehouse, simulation_engine, 
  report_builder)
- 4 ADK agents wired together (guardrail, ops_analyst, planner, narrator)

- 2 RAG retrievers working (metrics_catalog, brief_history)
- Daily monitoring loop running on schedule
- Deployed to Cloud Run
- One full end-to-end run produces a valid executive brief

# Stop condition

after done condition is met.
